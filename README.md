# Chess Coach AI — build 0.2.0

A dark, mobile-first Expo / React Native chess trainer.

## Features

- Interactive 8×8 chessboard with legal move highlighting
- Beginner Italian Game opening lesson
- Play against the computer as White
- Easy, Medium and Hard difficulty settings
- Stockfish online move selection when the public service is reachable
- Automatic local minimax AI fallback when offline or when the engine service is unavailable
- Undo, restart, game status and move review
- Import Chess.com PGN files or paste PGN text, then review each move with online Stockfish
- Android APK generated by GitHub Actions

## Run locally

1. Install Node.js 20 or newer.
2. Clone this repository.
3. Run `npm install`.
4. Run `npx expo start`.
5. Open the project in Expo Go, or use the Android emulator.

## Build an Android APK

Open the **Actions** tab and run **Build Chess Coach AI APK**, or push a commit to `main`. Download the generated `Chess-Coach-AI-APK` artifact from the successful workflow run.

The workflow installs dependencies with npm (the repository intentionally does not require a committed lockfile), aligns Expo package versions, runs Expo Doctor, generates the Android project and builds a release APK.

## Engine note

The app requests moves from the public Stockfish service at stockfish.online. It does not require an API key or paid subscription. If the service is unavailable, a built-in minimax chess AI plays instead. Engine availability depends on an internet connection and the third-party service.

Stockfish is GPLv3-licensed software. This app calls a public analysis service and does not bundle the Stockfish binary. See https://github.com/official-stockfish/Stockfish for licensing and source information.


## Stockfish engines (v0.6.0)

- **Auto** uses the bundled native Stockfish engine first and falls back to the online Stockfish analysis endpoint if local engine startup fails.
- **Local only** runs the bundled Stockfish engine on the device without internet access.
- **Online only** uses the online analysis service.
- Chess.com PGN review reports evaluation loss after each played move and labels moves Best, Excellent, Good, Inaccuracy, Mistake, or Blunder. This is an engine-depth-based approximation, not Chess.com's proprietary accuracy formula.
- Native engine dependency: `dawikk-stockfish` (Stockfish 17). Stockfish is licensed under GPL-3.0. See https://github.com/official-stockfish/Stockfish for the upstream source and license. The app bundles the native engine through the dependency; corresponding source and license obligations must be met when distributing builds.
- Local analysis uses CPU and battery; higher depth and long PGNs take longer.


## Game review update (v0.6.1)

The local engine now follows the UCI startup handshake (`uci` / `uciok`, `isready` / `readyok`) before analysing positions. The PGN review includes a White-vs-Black move-quality table and separate good-or-better totals. Move categories are estimates based on evaluation loss at the selected engine depth; they are not Chess.com's proprietary accuracy calculation.


## Opening library and offline Pass & Play (v0.7.0)

Learning mode includes 12 move-by-move opening lessons: Italian Game, Ruy Lopez, Scotch Game, Queen's Gambit, King's Gambit, Evans Gambit, Danish Gambit, Smith-Morra Gambit, Sicilian Defence, French Defence, Caro-Kann Defence, and London System. Each lesson includes a main line and strategic explanation.

Play mode includes **Pass & Play (Offline)** for two people sharing one device. Both sides make moves on the same board using `chess.js` legal move validation; the computer engine is not called in this mode. Standard check, checkmate, stalemate, and draw detection are provided by `chess.js`.


## Shared board and undo fix (v0.7.1)

Learn, Play, and Review are views over the same in-memory chess game. Switching tabs only changes the view and clears square selection; it does not start a new game. Undo reconstructs the position from the game’s original FEN when available (including imported PGNs), then replays all remaining moves. If reconstruction fails, the current position is left unchanged rather than resetting the board.


## Functional redesign and bot roster (v0.8.0)

Play now offers a bot roster with Martin (250 target Elo), Rookie (500), Club Player (1000), Tactician (1600), and Magnus-style (2800 target). Ratings are clearly described as target difficulty estimates, not official or measured playing strength. Martin uses deliberately casual random legal moves; other profiles use the available Stockfish engine with increasing search settings. The Magnus-style profile is the strongest available engine preset and does not claim to replicate Magnus Carlsen.

The refreshed visual theme uses a deep green chess-club palette, selectable bot cards, stronger selection states, and clearer engine status. Existing independent Learn, Play, and Review boards, opening lessons, PGN import, move classifications, undo, and offline Pass & Play are retained.
