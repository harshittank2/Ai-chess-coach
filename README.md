# Chess Coach AI — build 0.2.0

A dark, mobile-first Expo / React Native chess trainer.

## Features

- Interactive 8×8 chessboard with legal move highlighting
- Beginner Italian Game opening lesson
- Play against the computer as White
- Easy, Medium and Hard difficulty settings
- Stockfish online move selection when the public service is reachable
- Automatic local minimax AI fallback when offline or when the engine service is unavailable
- Undo, restart, game status and move review
- Android APK generated by GitHub Actions

## Run locally

1. Install Node.js 20 or newer.
2. Clone this repository.
3. Run `npm install`.
4. Run `npx expo start`.
5. Open the project in Expo Go, or use the Android emulator.

## Build an Android APK

Open the **Actions** tab and run **Build Chess Coach AI APK**, or push a commit to `main`. Download the generated `Chess-Coach-AI-APK` artifact from the successful workflow run.

The workflow installs dependencies with npm (the repository intentionally does not require a committed lockfile), aligns Expo package versions, runs Expo Doctor, generates the Android project and builds a release APK.

## Engine note

The app requests moves from the public Stockfish service at stockfish.online. It does not require an API key or paid subscription. If the service is unavailable, a built-in minimax chess AI plays instead. Engine availability depends on an internet connection and the third-party service.

Stockfish is GPLv3-licensed software. This app calls a public analysis service and does not bundle the Stockfish binary. See https://github.com/official-stockfish/Stockfish for licensing and source information.
